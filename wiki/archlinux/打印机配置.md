# 打印机配置（CUPS）

## 一、安装与启用

```bash
sudo pacman -S cups cups-pdf ghostscript
# 常用打印机驱动（按需安装）
sudo pacman -S cups-filters gutenprint

# 启用服务
sudo systemctl enable --now cups
```

## 二、添加打印机

### 2.1 图形界面（推荐）

浏览器打开 `http://localhost:631`，点击 **Administration → Add Printer**，输入系统用户名密码（root 密码，需加入 lp 组）。

按提示选择 USB / 网络打印机，选驱动后完成。系统桌面设置里的"打印机"入口也可用。

### 2.2 命令行方式

```bash
# 列出发现的打印机
lpinfo -v

# 列出驱动
lpinfo -m

# 添加打印机（以 USB 打印机为例）
sudo lpadmin -p 打印机名 -E -v usb://dev/usb/lp0 -m drv:///sample.drv/generic.ppd
```

### 2.3 打印测试

```bash
lp -d 打印机名 /usr/share/doc/cups/examples/hello.ps
lpstat -p   # 查看打印机状态
```

## 三、网络打印机（IPP / 共享）

Brother、HP 等网络打印机：

```bash
sudo pacman -S cups-pdf
# HP 网络打印机
sudo pacman -S hplip
# Brother 打印机（按型号搜索安装 brother-printer-driver-* 系列）
sudo pacman -S brother-printer-driver-mfc-j200
```

添加时选择 "Discover Network Printers" 或手动填写 IPP 地址：

```
ipp://192.168.1.100/ipp/print
```

## 四、扫描仪

```bash
sudo pacman -S sane sane-airscan simple-scan
```

USB 扫描仪接入后打开 `simple-scan` 即可识别。网络扫描仪用 sane-airscan 自动发现。

## 五、常见问题

| 问题 | 解决 |
|---|---|
| 打印队列卡住 | `sudo systemctl restart cups`，或删除任务 `cancel -a` |
| 找不到打印机 | 确认 `systemctl status cups` 正常运行；网络打印机确认 IP 可达 |
| 打印乱码 | 驱动不对，换 `gutenprint` 里的驱动重试 |
| 权限不足 | `sudo usermod -aG lp 用户名` 后重新登录 |

## 六、打印成 PDF

装好 `cups-pdf` 后打印时选择 "Print to PDF" 打印机，文件输出到 `~/Documents/PDF`。
