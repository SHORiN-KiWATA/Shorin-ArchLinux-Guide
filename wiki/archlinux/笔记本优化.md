# 笔记本优化


## 一、电源管理（TLP）

TLP 是笔记本最常用的电源管理工具，安装后即开即用：

```bash
sudo pacman -S tlp
sudo systemctl enable --now tlp
```

电池校准：

```bash
sudo tlp calibrate
```

查看状态：

```bash
sudo tlp-stat -s
```

> 注意：TLP 与 powertop 的 --auto-tune 不要同时用。如果使用 KDE，也可以只在桌面电源设置里调整，不装 TLP。

### 1.1 电池充放优化

```bash
# 查看电池状态
cat /sys/class/power_supply/BAT0/status

# 查看电量
cat /sys/class/power_supply/BAT0/capacity
```

支持 charge-threshold 的笔记本（ThinkPad 等）可以限制充电上限保护电池，编辑 `/etc/tlp.conf`：

```ini
START_CHARGE_THRESH_BAT0=80
STOP_CHARGE_THRESH_BAT0=80
```

## 二、屏幕亮度

### 2.1 快捷键调节

GNOME / KDE 桌面的 Fn 亮度键一般开箱即用。无效时安装：

```bash
sudo pacman -S brightnessctl
brightnessctl set 50%     # 设 50%
brightnessctl set +10%    # 增加 10%
```

把命令绑定到 Fn 键（见"桌面美化"章节的快捷键设置部分）。

### 2.2 命令行调节

```bash
# 列出可调设备
brightnessctl list

# 查看当前值
brightnessctl get
```

## 三、触摸板手势（libinput）

### 3.1 启用自然滚动与点击

GNOME 在系统设置 → 鼠标与触摸板中开启"点击触摸"与自然滚动。KDE 在 系统设置 → 输入设备 → 触摸板。

命令行方式，编辑 `/etc/X11/xorg.conf.d/30-touchpad.conf`（X11 环境）：

```
Section "InputClass"
    Identifier "touchpad"
    Driver "libinput"
    MatchIsTouchpad "on"
    Option "Tapping" "on"
    Option "NaturalScrolling" "true"
    Option "ClickMethod" "clickfinger"
EndSection
```

Wayland 下（GNOME/KDE 默认）系统设置即可完成，无需此文件。

### 3.2 三指 / 四指手势

- GNOME：系统设置 → 鼠标与触摸板 → 三指手势（任务切换、概览）
- KDE：系统设置 → 输入设备 → 触摸板 → 手势

Wayland 下的高级自定义手势可以用：

```bash
sudo pacman -S gesture
```

配合 `libinput-gestures` 需要切回 X11 会话，Wayland 下直接用桌面自带手势即可。

## 四、Fn 功能键

部分笔记本 Fn 键与媒体键颠倒。临时测试：

```bash
# 恢复 / 切换 FnLock（多数笔记本按 Fn+Esc）
echo 0 | sudo tee /sys/devices/platform/thinkpad_acpi/hotkey_tablet_mode 2>/dev/null
```

常见做法：
- ThinkPad：`Fn+Esc` 切换 FnLock
- 多数笔记本 BIOS 里有 "Fn and Ctrl Key swap" / "Fn Lock" 选项

## 五、合盖行为

```bash
# 查看当前合盖设置
systemd-inhibit --list
```

编辑 `/etc/systemd/logind.conf`：

```ini
[Login]
HandleLidSwitch=suspend
HandleLidSwitchExternalPower=suspend
```

合盖外接显示器时不想休眠，把 `HandleLidSwitchExternalPower` 改为 `ignore`。改完重启或 `sudo systemctl restart systemd-logind`。

## 六、CPU 性能模式

```bash
# 查看当前模式
cat /sys/devices/system/cpu/cpu0/cpufreq/scaling_governor

# 切换到省电 / 性能（需 amd_pstate 或 intel_pstate 支持）
echo powersave | sudo tee /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor
```

桌面环境（GNOME/KDE）都有图形化的性能模式切换，日常使用无需手动设置。
