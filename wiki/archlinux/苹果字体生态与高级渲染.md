## 推荐字体

苹果字体在排版、字重和清晰度上表现都很不错，适合作为 Linux 桌面的主力字体：

- **英文字体**：SF Pro（SF Pro Display / Text）- [San-Francisco-Pro-Fonts](https://github.com/sahibjotsaggu/San-Francisco-Pro-Fonts)
- **中文字体**：苹方（PingFang SC / TC）- [applePingFangFonts](https://github.com/witt-bit/applePingFangFonts)
- **等宽终端字体**：SFMono Nerd Font - [SF-Mono-Nerd-Font](https://github.com/epk/SF-Mono-Nerd-Font)

## 安装字体

建议安装到用户目录 `~/.local/share/fonts/apple/`，不受系统更新影响，无需 root 权限。

运行以下命令自动下载并安装：

```bash
# 1. 苹方（PingFang SC & TC）
mkdir -p ~/.local/share/fonts/apple/PingFang
curl -sL "https://github.com/witt-bit/applePingFangFonts/releases/download/3.0.1/pingFang-20.0d4e1.tar.gz" | tar -xz -C ~/.local/share/fonts/apple/PingFang/ --strip-components=2 "pingFang/pingFangSC" "pingFang/pingFangTC"

# 2. SF Pro
mkdir -p ~/.local/share/fonts/apple/SF-Pro
git clone --depth 1 https://github.com/sahibjotsaggu/San-Francisco-Pro-Fonts.git /tmp/sf-pro
cp /tmp/sf-pro/*.otf ~/.local/share/fonts/apple/SF-Pro/
rm -rf /tmp/sf-pro

# 3. SFMono Nerd Font
mkdir -p ~/.local/share/fonts/apple/SF-Mono
git clone --depth 1 https://github.com/epk/SF-Mono-Nerd-Font.git /tmp/sf-mono
cp /tmp/sf-mono/*.otf ~/.local/share/fonts/apple/SF-Mono/
rm -rf /tmp/sf-mono

# 4. 刷新字体缓存
fc-cache -fv ~/.local/share/fonts/apple/
```

## Fontconfig配置

编辑或创建 `~/.config/fontconfig/fonts.conf`。根据你的显示器类型选择对应的配置：

- **普通 LCD 屏幕**：开启次像素渲染（RGB 排列），字体边缘更清晰锐利。
- **OLED / 高分屏**：必须关闭次像素渲染（设为 none），改用纯灰度抗锯齿。因为 OLED 的子像素排列比较特殊，强开次像素渲染会导致文字边缘出现红蓝或绿色彩边；而 2K/4K 等高分屏像素本身就很密集，灰度抗锯齿反而最干净。

### LCD屏幕配置

适用于普通 1080p / 2K LCD 显示器：

```xml
<?xml version="1.0"?>
<!DOCTYPE fontconfig SYSTEM "urn:fontconfig:fonts.dtd">
<fontconfig>
    <!-- LCD 次像素渲染 -->
    <match target="font">
        <edit mode="assign" name="antialias"><bool>true</bool></edit>
        <edit mode="assign" name="hinting"><bool>true</bool></edit>
        <edit mode="assign" name="hintstyle"><const>hintslight</const></edit>
        <edit mode="assign" name="rgba"><const>rgb</const></edit>
        <edit mode="assign" name="lcdfilter"><const>lcddefault</const></edit>
    </match>

    <!-- 默认无衬线字体 -->
    <match target="pattern">
        <test qual="any" name="family"><string>sans-serif</string></test>
        <edit name="family" mode="prepend" binding="strong">
            <string>SF Pro Display</string>
            <string>PingFang SC</string>
            <string>Noto Sans CJK SC</string>
            <string>Noto Color Emoji</string>
        </edit>
    </match>

    <!-- 系统 UI 字体 -->
    <match target="pattern">
        <test qual="any" name="family"><string>system-ui</string></test>
        <edit name="family" mode="prepend" binding="strong">
            <string>SF Pro Display</string>
            <string>PingFang SC</string>
            <string>Noto Sans CJK SC</string>
            <string>Noto Color Emoji</string>
        </edit>
    </match>

    <!-- 等宽字体 -->
    <match target="pattern">
        <test qual="any" name="family"><string>monospace</string></test>
        <edit name="family" mode="prepend" binding="strong">
            <string>SFMono Nerd Font</string>
            <string>PingFang SC</string>
            <string>Noto Sans Mono CJK SC</string>
            <string>Noto Color Emoji</string>
        </edit>
    </match>

    <!-- 衬线字体 -->
    <match target="pattern">
        <test qual="any" name="family"><string>serif</string></test>
        <edit name="family" mode="prepend" binding="strong">
            <string>Noto Serif CJK SC</string>
            <string>Noto Color Emoji</string>
        </edit>
    </match>
</fontconfig>
```

### OLED与高分屏配置

适用于 OLED 屏幕（包含笔记本 OLED、QD-OLED）或高分辨率显示器：

```xml
<?xml version="1.0"?>
<!DOCTYPE fontconfig SYSTEM "urn:fontconfig:fonts.dtd">
<fontconfig>
    <!-- 纯灰度抗锯齿，彻底消除彩边 -->
    <match target="font">
        <edit mode="assign" name="antialias"><bool>true</bool></edit>
        <edit mode="assign" name="hinting"><bool>true</bool></edit>
        <edit mode="assign" name="hintstyle"><const>hintslight</const></edit>
        <edit mode="assign" name="rgba"><const>none</const></edit>
    </match>

    <!-- 默认无衬线字体 -->
    <match target="pattern">
        <test qual="any" name="family"><string>sans-serif</string></test>
        <edit name="family" mode="prepend" binding="strong">
            <string>SF Pro Display</string>
            <string>PingFang SC</string>
            <string>Noto Sans CJK SC</string>
            <string>Noto Color Emoji</string>
        </edit>
    </match>

    <!-- 系统 UI 字体 -->
    <match target="pattern">
        <test qual="any" name="family"><string>system-ui</string></test>
        <edit name="family" mode="prepend" binding="strong">
            <string>SF Pro Display</string>
            <string>PingFang SC</string>
            <string>Noto Sans CJK SC</string>
            <string>Noto Color Emoji</string>
        </edit>
    </match>

    <!-- 等宽字体 -->
    <match target="pattern">
        <test qual="any" name="family"><string>monospace</string></test>
        <edit name="family" mode="prepend" binding="strong">
            <string>SFMono Nerd Font</string>
            <string>PingFang SC</string>
            <string>Noto Sans Mono CJK SC</string>
            <string>Noto Color Emoji</string>
        </edit>
    </match>

    <!-- 衬线字体 -->
    <match target="pattern">
        <test qual="any" name="family"><string>serif</string></test>

            <string>Noto Serif CJK SC</string>
            <string>Noto Color Emoji</string>
        </edit>
    </match>
</fontconfig>
```

配置保存后执行 `fc-cache -fv` 刷新生效。

## 桌面与终端应用字体

### GTK 应用

可以使用 GSettings 命令直接修改：

```bash
gsettings set org.gnome.desktop.interface font-name 'SF Pro Display 11'
gsettings set org.gnome.desktop.interface document-font-name 'SF Pro Text 11'
gsettings set org.gnome.desktop.interface monospace-font-name 'SFMono Nerd Font 11'
```

或者写入 `~/.config/gtk-3.0/settings.ini` 与 `~/.config/gtk-4.0/settings.ini`：

```ini
[Settings]
gtk-font-name = SF Pro Display 11
```

### Qt 应用

安装 `qt5ct` 和 `qt6ct`，在图形界面里将字体设置为 `SF Pro Display` 即可：

```bash
sudo pacman -S qt5ct qt6ct
```

### 终端模拟器

- **Kitty**（`~/.config/kitty/kitty.conf`）：
  ```conf
  font_family SFMono Nerd Font
  font_size   12.0
  ```

- **Alacritty**（`~/.config/alacritty/alacritty.toml`）：
  ```toml
  [font]
  normal = { family = "monospace" }
  size = 12.0
  ```
  > 因为 fontconfig 已经把 monospace 设为 SFMono Nerd Font，这里写 monospace 就会自动使用它。

- **Ghostty**（`~/.config/ghostty/config`）：
  ```text
  font-family = SFMono Nerd Font
  font-size = 12
  ```

## 检查验证

在终端运行以下命令，看看字体是否正确生效：

```bash
# 检查默认无衬线字体
fc-match sans-serif

# 检查默认等宽字体
fc-match monospace

# 检查字体回退列表
fc-match -s sans-serif | head -n 3
```
