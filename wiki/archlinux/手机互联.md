# 手机与电脑互联

> 在电脑上收发短信、传文件、查看通知，Arch 下主要用 KDE Connect（KDE 生态）或 GSConnect（GNOME 生态）。

## 一、KDE Connect（KDE / 通用）

```bash
sudo pacman -S kdeconnect
```

手机端安装 **KDE Connect**（Play 商店 / F-Droid / 应用商店都有）。

连接步骤：
1. 手机和电脑连同一 Wi-Fi
2. 打开手机 App，配对请求，电脑端点击"接受"（或双方都打开 App 自动发现）
3. 配对后电脑端即可：收发短信、共享剪贴板、传文件、用手机遥控电脑、查看通知

共享剪贴板：

```bash
# 测试连接
kdeconnect-cli -l
# 发送文件
kdeconnect-cli --share 文件路径
```

## 二、GSConnect（GNOME）

GNOME 没有原生 KDE Connect，用扩展实现：

```bash
sudo pacman -S gnome-shell-extension-gsconnect
```

在 GNOME Extensions 应用里启用 GSConnect，再按 KDE Connect 的步骤配对即可，功能一致。

## 三、Firefox 浏览器连接（可选）

手机端装 KDE Connect 后，电脑 Firefox 安装 [KDE Connect 扩展](https://addons.mozilla.org/firefox/addon/kde-connect/)，可在浏览器里直接右键发送链接到手机。

## 四、传输大文件（局域网直连）

KDE Connect 传大文件较慢时，可以用系统自带工具：

```bash
# 同一局域网内直接传输（互传 App 的桌面版）
sudo pacman -S localsend
```

手机端装 LocalSend，电脑和手机打开后自动发现，传输速度吃满局域网带宽。

## 五、常见问题

| 问题 | 解决 |
|---|---|
| 发现不了设备 | 确认在同一网络、检查防火墙是否放行 `udp 1714-1764` / `tcp 1714-1764` |
| 剪贴板不同步 | 在 KDE Connect 设置里勾选"共享剪贴板" |
| 频繁掉线 | 无线网络隔离（AP 隔离）导致，关掉路由器 AP 隔离 |
| GNOME 下扩展不生效 | 确认 Wayland 会话下扩展版本与 GNOME 版本匹配 |
