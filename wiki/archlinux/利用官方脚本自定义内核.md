# 使用arch官方脚本自定义内核 #

## 1 拉取官方脚本 ##

~~~shell
sudo pacman -S devtools
#使用devtools进行拉取
pkgctl repo clone --protocol=https linux-zen
#拉取到home目录
~~~

## 2编辑PKGBUILD文件 ##

~~~shell
vim ~/linux-zen/PKGBUILD
~~~

建议更改包名

~~~shell
-pkgbase=linux-zen
+pkgbase=linux-zen-custom
~~~

定位到prepare()函数

~~~ shell
#如果想要极致优化开启LTO的话需要在函数开头添加:
export LLVM=1
export LLVM_IAS=1 //需已安装llvm clang lld

#函数最后添加
make menuconfig //启用自定义配置菜单

可选：添加make localmodconfig #按照机器正在使用的模块精简要编译的驱动，这个风险有点高，添加后会减少编译时长和模块大小但不会提高内核性能，还可能会导致某些设备挂掉
~~~
## 3编译前的准备 ##

默认编译只会动用一个cpu核心要是再在内核里再开启LTO和-03优化要编译一整天

可以在build()函数里更改以启用多核编译

~~~ shell
-make all
+make all -j$(nproc)
#这里$(nproc)代表使用所有核心可以用数字代替
~~~

或者直接更改makepkg.conf文件让以后的每个编译任务都启用多核编译

~~~shell
sudo vim /etc/makepkg.conf
~~~

~~~shell
MAKEFLAGS="-j$(nproc)" #确认该行未被注释
~~~

## 4开始编译 ##

~~~shell
makepkg -s 
#还有一个-sL的写法---编译时加上日志，但是实测会出现半屏显示和无法操控方向键的问题
#makepkg -sL
~~~
根据鲸鱼娘的解释:
~~~text
真正元凶是 -L。makepkg 开日志时把该函数的 stdout 和 stderr 一起接进日志管道再 tee，ncurses 拿不到真实窗口尺寸就退回 80x24（所以是「半屏」），keypad 的进入序列被写进日志文件而不是终端，终端停在普通模式，方向键于是失灵（留下 ^[[A）。
~~~
~~~shell
#另外要是中途编译失败或是不小心中断了需要先清理坏掉的编译产物
rm -rf src pkg 
make -s
~~~
脚本会从官方拉取linux-zen的源码

然后将内核配置对应正在使用的内核配置然后将新的配置按默认处理

最后打开选项菜单

关闭完选项菜单就会正式开始编译任务

### 接下来是一些配置建议 ###

#### 1开启-O3优化 ###

~~~text
General setup
└──Compiler optimization level (Optimize more for performance (-O3))
~~~

ps:linux-zen内核默认已经开启-O3优化

#### 2开启LTO优化 ###

~~~text
General architecture-dependent options
└──Link Time Optimization(LTO) #默认None,内存充裕直接拉满选Full LTO
~~~

#### 3Processor type and features选项优化 ####

如果内核只在自己的机器上运行且短期不会更换CPU的可以勾选

~~~text
Build and optimize for local/native CPU
~~~

如果你是intel用户的化可以把这里所有带amd的都取消勾选

如果内核不需要在虚拟机运行的可以取消勾选

~~~text
Linux guest support
~~~

## 5编译后的工作 ##

#### 安装内核和头文件 ####

不精简模块的源码树文件编译完大概会有30几个G但我们只需要其中的部分文件即可

~~~shell
sudo pacman -U linux-zen-custom-7.2.8.zen1-1-x86_64.pkg.tar.zst linux-zen-custom-headers zen1-1-7.2.8-x86_64.pkg.tar.zst
#安装内核和头文件 包名不一定相同
sudo grub-mkconfig -o /boot/grub/grub.cfg
#更新grub
reboot
#重启后应该就能在grub的高级选项里看到自定义的内核了
~~~

另外还会有一个docs包，再让鲸鱼娘解释一下吧~~

~~~text
这个包包含了随 Linux 内核源码一同分发的 HTML 格式文档。这些文档非常详尽，覆盖了内核的各个子系统、文件系统、驱动程序的开发笔记等，是进行内核开发或深度定制时的重要参考资料
																		-----deepseek
~~~

## 后话 ##

桌面linux本就小众捣鼓内核更是小众中的小众，我想一个shorin都没讲过的内容应该也不会有多少人感兴趣吧

在当今的硬件基础上对内核进行自定义得到的性能是比较小的，自定义的价值更多体现在了解内核的一些功能作用原理及其由来~~不是让你去当佳豪的~~

内核的配置应该是一个循序渐进的过程，不要说把自己的电脑配置和配置菜单发给ai然后照着把每个选项都改一遍

也不要让agent来帮你选择，这体现不了自定义内核的价值

这样只会得到一个天天出问题然后社区没人会帮agent看不懂的垃圾内核
